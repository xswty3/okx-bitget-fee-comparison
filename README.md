## 手续费：0.01个百分点，一年差多少钱

先算单笔。1万美元的U本位永续吃单一次，欧易收5.00美元，Bitget收6.00美元，差1美元。

按月交易10万美元名义价值、挂单和吃单各占一半来算：

- 欧易：50,000×0.02% + 50,000×0.05% = 10 + 25 = **35美元/月**，一年420美元
- Bitget：50,000×0.02% + 50,000×0.06% = 10 + 30 = **40美元/月**，一年480美元
- 一年差 **60美元**

现货的差距反而更大，因为欧易挂单只要0.08%。同样每月10万美元、挂吃各半：

- 欧易：50,000×0.08% + 50,000×0.1% = 40 + 50 = **90美元/月**，一年1,080美元
- Bitget：50,000×0.1% + 50,000×0.1% = **100美元/月**，一年1,200美元

如果Bitget那边用BGB支付现货手续费，现货降到0.08%，跟欧易持平，年差额归零。合约没有这层抵扣，0.01个百分点的差距一直在。
